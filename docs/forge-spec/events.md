# Forge 1.8.9 event catalogue

Generated by `tools/forgespec` (bytecode scan of forge-1.8.9-11.15.1.2318 universal jar, remapped notch -> SRG/MCP; patch scan of the Forge `1.8.9` branch) plus hand-curated notes in `tools/forgespec/curated_events.py`. Machine-readable form: `events.json`.

Columns: **C** = `@Cancelable` (own or inherited; `post()` returns true if cancelled), **R** = `@HasResult`, **Side** = logical side(s) the post executes on, **MP** = needed by a multiplayer-only client (`yes`, `partial`, `no` = server/singleplayer only, listed but out of scope). **Fired at** gives `Forge-class.method` (compiled-line in `src/main/java/...`) and, for vanilla-triggered hooks, the vanilla caller (MCP names) and the Forge patch hunk (`patches/minecraft/...patch:line`).

Buses: `MinecraftForge.EVENT_BUS` (all `net.minecraftforge.*` events, plus `FMLNetworkEvent`, `ConfigChangedEvent`, `FMLNetworkEvent`), `FMLCommonHandler.instance().bus()` (`TickEvent.*`, `InputEvent.*`, `gameevent.PlayerEvent.*`), `MinecraftForge.TERRAIN_GEN_BUS` and `MinecraftForge.ORE_GEN_BUS` (terrain/ore generation; all server-only).

Inheritance: a listener for an event class also receives subclass events; per priority, listeners of the most-derived class run before listeners of its parent classes (ListenerList.java:160-170). `Cancelable`/`HasResult` are inherited through the generated `isCancelable()`/`hasResult()` overrides (EventSubscriptionTransformer.java:101-160).

Totals: 245 event classes (186 with an identifiable construct site), 70 cancelable, 21 with result.
